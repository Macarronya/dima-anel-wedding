ОБНОВЛЕНИЕ: БЛОК О ТЕМАТИКЕ И ПОДГОТОВКЕ

В архиве находятся только файлы, которые нужно обновить/добавить:
- index.html — добавлены блоки после даты и адреса;
- styles.css — добавлено оформление новых блоков;
- assets/mood-color.svg;
- assets/mood-shapes.svg;
- assets/mood-details.svg.

Другие файлы проекта не меняются: config.js, script.js и google-apps-script.gs оставьте текущими.

Как загрузить:
1. Замените index.html и styles.css в корне репозитория.
2. Загрузите три SVG-файла в папку assets.
3. Сделайте Commit changes.
4. Подождите обновления GitHub Pages и нажмите Ctrl+F5.

Позже SVG-референсы можно заменить настоящими фотографиями, сохранив те же имена файлов.
